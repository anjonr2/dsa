What is a Linked List?

Imagine you are given a task where you have to maintain a data entry of cars entering a parking lot. Since the number of cars entering will be different and may change daily, constructing a fixed sized data structure like an array might not be helpful. This is when the list comes in picture, which allows us to add and remove cars easily. Linked List is a linear data structure that can be visualised as a chain with different nodes connected, where each node represents a different element. The difference between arrays and linked lists is that, unlike arrays, the elements are not stored at a contiguous location

For any element to be added in an array, we need the exact next location to be empty

A linked list is a data structure containing two crucial pieces of information, the first being the data and the other being the pointer to the next element. The head is the first node and the tail is the last node in a linked list

Application of Linked Lists : 
Creating Data Structures : Linked Lists serve as the foundation for building other dynamic data structures, such as stacks and queues 

Dynamic memory Allocation : Dynamic memory allocation relies on linked lists to manage and allocate memory blocks efficiently

Web browser : is one important application of Linked List
